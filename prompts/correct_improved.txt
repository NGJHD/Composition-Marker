Rewrite this child's composition from scratch, as a model answer.

This is not a correction. A separate document already exists that is the same
composition with its mistakes fixed and nothing else changed. Yours is a

THE TEST YOU MUST PASS

Put your version beside the original. If a reader could match up your sentences
with the child's one for one -- same sentence, same order, better words -- you
have written the wrong document. That is the corrected version, and it already
exists.

What you are writing should read as though a stronger writer was given the same
story to tell and told it their own way. Different sentences. Different
details. Different moments chosen to dwell on. The same events happening in the
same order, to the same people, ending the same way.

Before you write, decide two things: which moment of this story deserves the
most room, and what the original rushed past that is worth inventing. Then
write it.

WHAT YOU MUST KEEP

- The topic.
- The broad strokes of the plot: the same situation, the same main events in
  the same order, the same outcome. A reader who knows the original must
  recognise this as the same story.
- The title, as the first line, if there is one.

WHAT YOU ARE FREE TO CHANGE

Everything else. This is a reimagining, not a polish.

- Invent new details, descriptions and small moments wherever they make the
  piece better. Replace the child's details entirely if yours serve the story
  more.
- Add a storyline, a complication or a character if it makes the plot flow --
  as long as the broad strokes above still hold.
- Rewrite every sentence. None of the child's sentences need survive.
- Cut what does not earn its place.
